## 项目简介

CareerPilot 就业罗盘面向中国校招、社招求职者及参赛开发者，提供简历分析、岗位匹配与面试训练的一体化工作台。上传 PDF、Word 或图片简历后，由本人核对提取的画像信息；系统按确定性规则引擎计算六维岗位适配分（技能 25%、经历 25%、学历 15%、科研 15%、奖项 10%、意向 10%），给出亮点前置的简历优化建议，并开展千问出题、DeepSeek 评审的文本面试。诊断报告与简历草稿可导出 HTML/JSON 并打印为 PDF。所有评分只基于用户已确认的事实，不编造经历，不代表录用概率。

## 主要功能与智能体方案

前端采用 Next.js 16 / React 19，后端 FastAPI 负责任务编排与引用校验，SQLite 保存业务记录，本地 Dify 1.19 承载 17 个已发布工作流，提示词版本化管理。模型调用阿里云百炼 API：千问负责写作与出题、DeepSeek 负责评审复核、Tavily 负责联网检索，凭据只保存在服务端。核心亮点是位于业务层的确定性规则引擎：纯函数、无模型调用、毫秒级返回，六维加权评分借鉴公开简历筛选 rubric，每缺一项必需技能折减 15 分（下限 25 分），科研与奖项只识别简历原文、分层计档。业务流程为上传 → 核对 → 匹配 → 诊断 → 面试；简历原文不进入搜索词，网页内容视为不可信数据，私网地址与重定向被拦截，相同 request_id 不重复计费。

## 项目创新点或特色

与现有 AI 求职工具相比，本项目的不同在于让"可信"成为架构属性而非提示词承诺。**第一，确定性评分先于模型生成**：同一输入永远同一分数，每个数字可指回具体规则并复算，纯模型打分做不到这一点。**第二，事实锁定**：每条成稿句子映射用户已确认的 fact_id，画像修改后旧草稿自动标记失效，个人与团队成果不混淆。**第三，引用可核对与诚实降级**：「已查证」结论必须带来源 ID 与逐字片段并由后端校验；断网或无凭据时明确标注"未联网核验"，通用建议与官方要求分开，绝不伪装成功。诊断报告由六维得分驱动，给出"亮点前置、普通简化"的可执行排版建议而非空话。

## 当前基础与下一步计划

已完成简历上传与画像核对、六维规则评分与岗位适配排序、诊断报告、文本面试、HTML/JSON 导出，以及面向开发者的 /developer 精准场景攻略页（求职/面试/比赛三类，联网来源可逐条点开）。验证方面：17 个 Dify 工作流真实链路通过，22 项浏览器回归全部通过，五种视口截图无横向溢出，规则引擎自校验通过。下一步：DOCX 原生简历导出并通过真实 ATS 验证；建立官方域名白名单并接入更多检索源；比赛真题库（仅收录公开来源）；六维权重开放自定义配置；多人协作与设备间同步。尚待解决：联网检索需配置 Tavily Key（未配置时诚实标注），职业影像功能因供应商额度限制暂时关闭。

## 已有应用或测试情况

已提供 1 份虚构简历、10 条示例岗位和 55 条经官方核对的职业分类资料；连接千问后无需简历即可聊天。22 项桌面/手机浏览器回归、来源和报告检查通过，GitHub CI 通过。聊天测试覆盖连续追问、清空、错误重试和上下文限制。规则引擎 demo 自校验通过，17 个 Dify 工作流真实链路（场景攻略、简历指导、段落润色、草稿生成、攻略复核）全部实测通过。尚无真实用户试用数据；真实云生成与 OCR 质量仍待有效账户验证。

## 其他补充说明

职业名称、代码与分类依据技能人才评价工作网公开职业分类系统逐条核对，精选 55 个条目；工作方向说明、国内常见岗位称呼、关键词和评分由项目独立编写，不转载官方职业定义与工作任务全文，不作为国家职业标准、资格认定或实时招聘信息。简历须授权并脱敏，云调用由用户阿里云账户计费。聊天不自动附带简历，不写业务数据库，刷新或清空后移除；Key 按会话暂存内存。尚无完整账号、自助删除和自动保留期清理；公开演示优先使用合成数据。
