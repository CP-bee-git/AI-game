# 中国职业数据来源核对

核对日期：2026-10-30。用途：为 CareerPilot 的职业方向匹配提供中国职业代码和名称，替代美国 O*NET 分类。

## 权威来源

- [技能人才评价工作网·职业分类系统](https://www.osta.org.cn/career)：网站页脚列明政策指导单位为人力资源和社会保障部职业能力建设司，版权所有单位为中国就业培训技术指导中心、人力资源和社会保障部职业技能鉴定中心。
- 官方网页实际调用的公开查询端点为 `/api/client/career/query?careerCodeAndName=关键词`；详情为 `/api/client/career/detail?careerCode=代码&versionId=2`；分类树为 [`/api/client/get/tree`](https://www.osta.org.cn/api/client/get/tree)。核对时均可直接读取，无需账户。
- [官方网站声明](https://www.osta.org.cn/wangzhanshengming.html)限制商业性转载，其他单位提供的信息和服务另有授权要求。该网站未标注 CC BY 开放数据库许可；不可沿用 O*NET 的 CC BY 4.0 标识。

以上是网页使用的内部端点，不是承诺稳定的开放 API。产品应读取经核对的本地事实快照，避免把外部站点可用性变成用户匹配流程的依赖。

## 快照与匹配边界

1. 职业代码、名称和分类是核实对象；国内常见招聘名称作为项目整理的检索别名。一个招聘名称不能擅自生成一个国家职业代码。
2. 职业介绍、国内工作场景、技能关键词、别名和评分均由项目编写，清楚区分于官方职业分类；不整库转载网站原文定义、工作任务，不宣称官方推荐或国家能力测评。
3. `versionId=2` 是站点接口参数，不能单凭这个数字推断资料为某年冻结版。当前系统已包含后续新增职业，标明核对日期与精选范围，不声称完整收录《职业分类大典（2022年版）》或全部最新职业。
4. 职业分类不等于职业资格许可或实时招聘数据。匹配分数只说明已确认资料与项目关键词的对应程度；没有证据时显示零分，并保留十个不同职业供继续了解。
5. 旧分类和网络资料可能保留不同代码。例如本次官方查询的互联网营销师代码是 `4-01-06-02`；不可混用旧版资料中的 `4-01-02-07`。

维护时应逐条复核代码、名称、分类及来源，保留来源 URL 和核对日期，再运行职业库和报告检查。

## 本项目采用的快照

`backend/app/data/occupations.json` 收录 55 个职业，覆盖软件、数据、商业运营、财务、人力、供应链、设计、文化、教育、工程等 10 个项目分组。每个条目记录官方名称（保留数字/绿色职业标记的原始名称）、代码、官方大中小类、详情链接及事实记录 SHA256。分组、工作方向说明、常见岗位称呼与关键词均为项目自行整理，不与官方分类层级混淆。

事实哈希仅包含 `careerCode/name/bigCode/bigName/centreCode/centreName/smallCode/smallName/versionId`，按 JSON 键排序、无额外空白、UTF-8 序列化后计算 SHA256。不收录网站原文定义或工作任务全文。

匹配使用等权关键词与精确同义词，去重后计算用户技能覆盖和证据广度；规则在返回的 `catalog.scoring_method` 中公开。不能把项目关键词的缺项解释成法定从业要求。

验证：

```bash
.venv/bin/python backend/scripts/check_careers.py
.venv/bin/python backend/scripts/check_careers.py --verify-source
```

第二个命令需要联网，仅用于维护时验证 55 条官方事实；普通用户匹配使用随项目发布的快照，不依赖外站实时可用。
